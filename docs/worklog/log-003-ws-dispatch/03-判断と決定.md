# 03 判断と決定

- 層は **framework 非依存の `WsConnection` クラス**（`src/net/connection.ts`）に集約。Unity(C#) が 1:1 でミラーしやすいよう、React 依存を持ち込まない（docs/rules/01 §5）。
- React 用は薄い `useWsConnection` フックを別ファイルに分離（生成・破棄・status 購読のみ）。
- ディスパッチは `on(type, handler)` 登録 → 受信 Envelope の `type` で振り分け。**未知/未購読 type はログも警告もせず無視**（contract 前方互換・クラッシュ回避）。
- 自動再接続（既定 1s）を実装。明示 `disconnect()` 時は再接続しない。
- **ゲームロジック・state 畳み込みは一切持たない**（#5 の責務）。payload は `unknown` のまま渡し、解釈は呼び出し側。
- 接続先は `import.meta.env.VITE_WS_URL` から取得（直書きしない・docs/rules/02 §4）。
