# 04 成果物

- `src/net/connection.ts` — `WsConnection`（connect/disconnect/自動再接続/send/on/onStatusChange）
- `src/net/useWsConnection.ts` — React フック
- `src/net/index.ts` — barrel

## 要点
- `send(type, payload)` は `Envelope { type, payload }` を JSON 化して送信。未接続時は false。
- `on(type, handler)` は解除関数を返す。同一 type に複数登録可。
- 受信は `handleRawMessage` で JSON parse → type 検証 → 該当ハンドラへ。非文字列フレーム・parse 失敗・type 欠落・未知 type はすべて安全に無視。
