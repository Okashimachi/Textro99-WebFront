# 03 判断と決定

- `create-vite` は対話式のため使わず、設定ファイルを直接作成した（非対話・再現性重視）。
- パスエイリアス `@/*` は tsconfig（`paths`）と Vite（`resolve.alias`）の両方に設定。既存 `src/proto/types.ts` を `@/proto/types` で参照可能にした（vendored ファイルは無改変）。
- `node:url` を Vite 設定で使うため `@types/node` を devDependency に追加。
- 状態管理ライブラリは入れない（docs/rules/02 §3）。React 標準の useState/useReducer のみ。
- `.env` は gitignore 済み。`.env.example` に `VITE_WS_URL` 雛形のみ置き、秘密情報はコミットしない（docs/rules/03）。
