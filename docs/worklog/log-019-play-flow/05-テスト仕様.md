# 05 テスト仕様

## 前提条件

- proto v0.1.1
- `npm run dev`（Vite）。実サーバーは `VITE_WS_URL`（検証時点: `wss://34-105-93-205.sslip.io/ws`）。

## テストケース

| # | 種別 | 確認項目 | 手順 | 期待結果 |
|---|---|---|---|---|
| 1 | 自動 | 型整合 | `npm run typecheck` | エラー 0 |
| 2 | 自動 | ビルド | `npm run build` | 成功 |
| 3 | 手動 | タイトルの2入口 | タイトルを開く | 「プレイする」（主）と「テスト用」（副）が並ぶ |
| 4 | 手動 | play はモード選択を飛ばす | 「プレイする」を押す | 直接プレイヤー名入力へ進む |
| 5 | 手動 | play の戻り先 | 名前入力で「← 戻る」 | モード選択ではなくタイトルへ戻る |
| 6 | 手動 | test は従来どおり | 「テスト用」を押す | モード選択（オンライン/練習/部屋=近日）が出る |
| 7 | 手動 | play で開発ツールが出ない | play で対戦開始 | 送信ログ / Dev モック / RawStateDebugPane / 開発ツール切替が一切出ない。ヘッダーは名前のみ |
| 8 | 手動 | test で開発ツールが出る | test → オンラインで対戦開始 | 従来どおり開発ツールと「画面: / 接続: / 生存:」が出る |
| 9 | 手動 | 名前がサーバーに届く | play で名前を入れて開始 | `MatchmakingJoin{displayName}` が送信され、盤面の自分の名前が入力値になる |
| 10 | 手動 | 人数待ち表示 | 最低人数未満で待機する | 「あと N 人でカウントダウン開始」が出る |
| 11 | 手動 | カウントダウン表示 | 最低人数到達後 | サーバー `countdownMs` に沿って「開始まで Ns」と「この間も他のプレイヤーが参加できます」が出る |
| 12 | 手動 | 開始ゲート | MatchStart 受信後 | 「まもなく開始」3→2→1 の後に試合画面へ |
