## 実装/変更の要点

- **入口の2系統化**: `play`（実運用）= title → 名前入力 → クイックマッチ。`test`（開発）= title → モード選択 → 名前入力 → 各モード。従来フローは `test` 側にそのまま残しており、挙動を変えていない。
- **開発ツールの分離**: `showDevToolsPref`（ユーザーの ON/OFF 設定）と `devToolsAvailable`（入口による可否）に分け、`showDevTools = devToolsAvailable && showDevToolsPref` で合成。play 入口では切替UI自体を描画しない。
- **30秒はサーバー所有**（[03](./03-判断と決定.md) 判断A）。フロントに秒数を持たせず `countdownMs` を描画するだけ。
- 名前は既存の接続 open 時 `MatchmakingJoin{displayName}` 経路をそのまま使う（本 PR で通信は増やしていない）。
