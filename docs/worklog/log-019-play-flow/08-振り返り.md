# 08 振り返り

## うまくいった点

- **指示の文面をそのまま実装しなかった**こと。「30秒の猶予を持たせて」を額面どおりフロントのタイマーとして実装すると rules/01 §1,§3 違反かつクライアント間で開始がズレる。着手前に確認したところ「サーバーで実装済み、それをそのまま使う」と確定し、フロントは表示だけで済んだ。
- 既存の `test` フローに一切手を入れずに `play` を追加できた。`Entry` フラグ1つで遷移と開発ツールの両方を切り替える形にしたため、分岐が散らばらなかった。
- 名前の送信は既存の `MatchmakingJoin{displayName}` 経路をそのまま使えたので、通信を増やさずに済んだ。

## 詰まった点 / 反省

- **待機画面の2状態を検証できなかった**。実サーバーは常に試合中で即 MatchStart、モックは `MatchmakingStatus` を送らない。表示ロジックを変更した箇所なので、未検証のまま残っているのは弱い。
- 実サーバーに接続して**進行中の試合に実際に参加してしまった**（即脱落・5位）。検証用の接続が実データに混ざる点は、共有サーバーだと他プレイヤーへの影響もありうる。検証専用の接続先やモードがあると安全。
