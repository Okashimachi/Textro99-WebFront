## 実装の要点

### 共有テキスト（モック）

```
👑 テキストロ99 で優勝しました！        テキストロ99 で 42位 でした
撃破 8人 / 最大コンボ 45                撃破 2人 / 最大コンボ 18

#テキストロ99                           #テキストロ99
```

- 使う値は `GameOver` の `rank` / `koCount` / `typingStats.maxCombo` のみ（サーバー確定値の文字列整形だけ）。
- ハッシュタグは `#テキストロ99` の1本。`hashtags` パラメータではなく本文末尾に直書きする（intent の `hashtags` は挙動が環境で揺れるため）。

### X への遷移

- `text` と `url` を**分離**して `URLSearchParams` に渡す。`url` は intent 側が本文末尾に付ける。
- `window.open(url, "_blank", "noopener,noreferrer")` で別タブ。開くだけで投稿は確定しない。
- `VITE_SHARE_URL` 未設定時は `url` パラメータを付けない。

### UI 配置

- `ResultActions` の「再マッチング / タイトルへ」の**下・右寄せ**に小さく置いた。主導線より弱い扱いにして、決着後の行き先選択の邪魔をしない。
- ボタンの `title` に投稿本文をそのまま入れてある（ホバーで内容を確認できる／検証時にも使える）。
