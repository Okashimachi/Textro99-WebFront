# 03 判断と決定

- 画面フェーズは原則 **サーバー state（ViewModel）から導出**（`deriveScreenPhase` 純関数）。描画は受信 state 経由（docs/rules/01 §3）。
- サーバー state で表せない部分だけをローカル意図 `LocalIntent`（`idle`/`seeking`/`dismissedResult`）で補う。
- 優先順位: リザルト > 試合中/観戦 > 待機 > タイトル。
- **観戦は「試合中だが自分が脱落 → 自操作無効化」**として表現（#9 の暫定方針）。`isInputActive` は `inMatch` のみ true。
- リザルト離脱の不具合修正: `rematch`/`backToTitle` は `GameOver` が state に残っていても離脱できるよう、`result` 表示条件を `intent === "idle"` に限定した（当初 `!== "dismissedResult"` では rematch 後もリザルトに留まる不具合をブラウザ検証で発見・修正）。
- 実際の Join/Leave 送信は #10、HUD 中身は #11/#12、リザルト中身は #13 に委譲。ここはルーターとプレースホルダのみ。
