# 03 判断と決定

- 入力は `PlayerView[]`（PlayerSummary + Delta 由来 `stackRatio`）のみ。Delta マージは reducer #5 済みなので、本コンポーネントは表示に徹する。
- 11 列グリッドで 99 セル。生存中は危険度（stackRatio、無ければ count/limit）で色替え、脱落は `×`＋暗色、バッジ数を右上に表示。自分セルは ring 強調。
- **ターゲティング先の確定・推定はしない**（サーバー権威）。危険度色は表示のしきい値色分け。
- 高頻度 Delta / 低頻度フルの反映は reducer 側の責務。ここは props の配列を描くだけ。
