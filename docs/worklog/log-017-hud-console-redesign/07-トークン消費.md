# 07 トークン消費

## サマリ

| 項目 | 値 |
|---|---|
| 概算トークン消費 | 入力 ~180k / 出力 ~20k（概算） |
| セッション往復数 | 約 35 |
| 手戻り回数 | 1（グリッドの高さ調整） |
| 主な消費要因 | 既存 HUD 一式の読み込み、ブラウザでの目視確認の往復 |

## 消費の過程・原因の分析

- 既存 HUD コンポーネント 10 ファイルをまとめて読み込んだ分が入力の大半。
- ローカルの 5173 が使用中で dev サーバー起動をやり直し、ブラウザ操作の往復が増えた。

## 次回への改善案

- デザイン刷新のように「全 HUD を触る」タスクは、最初に1回のバッチ読み込みで済ませる（今回は実施できた）。
- 画面確認は Dev モック注入をまとめて 1 回の JS 実行で行う（今回途中から実施）。
