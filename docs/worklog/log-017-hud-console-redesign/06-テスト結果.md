## 追加対応（配色の指摘を受けて）

- 事象: 起動済みの dev サーバー（:5173）で **色が完全に消えていた**。
  原因は `tailwind.config.js` の独自トークン追加を dev サーバーが読み込んでおらず、
  新クラスが CSS に生成されていなかったこと（要再起動）。
- 対応: 独自トークンを廃止し **Tailwind 標準パレットへ全面置換**（再起動不要にする）。
  あわせて役割ごとの配色（赤/琥珀/緑/青/黒）を割り当て、パネルヘッダも色分けした。
- 再確認: 新しい dev サーバーで各パネルの配色を目視確認、`npm run build` も成功。
