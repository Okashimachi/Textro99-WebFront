# 03 判断と決定

## 決定

1. **カラートークンを tailwind.config.js に追加**（`paper` / `panel` / `head` / `line` / `ink` / `sub` / `accent` / `ok` / `warn`）。
   個々のコンポーネントに生の hex を散らさず、後からテーマを差し替えられる状態にする。
2. **`Panel` 共通コンポーネントを新設**（`src/components/hud/Panel.tsx`）。
   モック画像の「色チップ＋ラベル＋右端の補助情報」を持つヘッダ帯を1箇所に集約する。
3. **AttackWarningBar を盤面のオーバーレイから右列の常設パネルへ移動**。
   モックの `IN — 被弾予告` に合わせ、予告 0 件でも枠を残す（レイアウトが跳ねない）。
4. **PlayField から「天井がせり下がる」演出を撤去**し、被弾スタックを横セグメントバーに変更。
   モックの表現に合わせ、NEXT は縦積みカードから行リストへ。
5. **ComboGauge のリングメーターを廃し、OUT パネル（大きな数値＋10段ブロック）に変更**。
   コンポーネント名・props は据え置き（用語集・呼び出し側を変えない）。
6. **セットアップ／マッチング／リザルト画面も同じ白地テーマへ**追従（暗色のままだと同一アプリに見えないため）。
   `RawStateDebugPane` は開発用オーバーレイなので暗色のまま残す。

7. **独自カラートークン（`accent` 等の theme.extend）をやめ、Tailwind 標準パレットだけで組む。**
   初回実装では `tailwind.config.js` にトークンを追加したが、**config 変更は dev サーバー再起動が要る**ため、
   起動済みのサーバーでは新クラスが生成されず「色が全部消える（素の黒白）」状態になった。
   標準パレット（zinc / red / amber / emerald / sky）だけなら再起動なしで常に色が出る。
8. **配色に意味を持たせる**（無彩色ばかりにしない）:
   赤=自分の攻撃・危険 / 琥珀=注意・撃破バッジ・MAX / 緑=安全・打鍵確定 / 青=お題と作戦（情報系） / 黒=脱落・自分の行。
   パネルのヘッダ帯も役割色で塗り分け、視線がどのパネルの話か即分かるようにした。

9. **配置を「中央の主ディスプレイ固定」に再構成**（人間の指示）:
   - 中央: 作戦（上）→ 主ディスプレイ（いま打つお題）→ 攻撃力 OUT（下）。視線移動を縦一列に収める。
   - 左: 敵の状況（99人グリッド）／被弾予告 IN／戦況ログ。
   - 右: NEXT（下端が「次」で上へ積み上がる）／ランキング。
   これに伴い **NEXT を PlayField から `NextQueue.tsx` に分離**（1パネル1役割）。
   `PlayField` は被弾スタックと現在のお題＋打鍵進捗だけを持つ。
10. 練習モード（`src/dev/mockServer`）が常に1件しかお題を持たず NEXT を確認できなかったため、
   実サーバー同様に**数件先まで積む**よう先読み発行を追加した（開発用スタブの挙動のみ）。

11. **視認性の強化（人間の指示）**:
   - ヘッダは「残り人数」「撃破数」だけに絞り、色付きの大枠＋5xl の数字で強調（順位/難易度/MATCH ID は削除）。
   - NEXT は**ひらがなのみ**に簡略化（種別ラベル・Lv・ローマ字を削除）し、種別は色で区別＝多くの件数を縦に並べられる。
   - **被弾予告パネルを廃止**（`AttackWarningBar.tsx` を削除）。飛来する攻撃はトラップ／被弾ダケンとして
     NEXT に色付きで並ぶため、専用パネルは二重表示だった。
   - **被弾スタックパネルも廃止**（`DakenStackView.tsx` を削除）。溜まり具合は NEXT 左のレールが担い、
     ヘッダ右に「あと N でゲームオーバー」を出す＝NEXT を見るだけで残余が分かる。
   - コンボは主ディスプレイ右下の**円形バッジ**へ統合（`ComboGauge` はパネル → バッジに作り替え）。
   - 99人グリッドは**常に 99 マス**を描き、未参加の席は破線＋✕ の「欠席」にした（練習/少人数でも盤面が崩れない）。
   - 戦況ログは主ディスプレイ直上の**通知**に変更。種類ごとに色とタグ（撃破/攻撃/相殺/決着/情報）を出す。
   - 注記: `incomingAttacks` は ViewModel 側に残している（サーバー由来データを捨てない）。表示だけをやめた。

12. **左ブロックを2列（ランキング : 敵の状況 = 0.72 : 1.28）に分割**（人間の指示）。
   左ブロック全体の幅は変えずに内側だけを割ったので、**主ディスプレイの大きさ・位置は不変**。
   どちらのパネルも `h-full` で縦に揃え、縦長のコンポーネントとして並ぶ。
13. **NEXT の積み上げ方向を反転**（上が「次」・下へ溜まる）。次の1件だけ高さ2倍・2xl で強調する。
   溜まり具合は左レールをやめて**窓全体の地色**で表現し、危険域（85%以上）は
   `animate-soft-alert`（2.2秒周期で薄赤↔赤へ）でゆっくり点滅させる。

14. **危険域の警告を背景→前景に変更**（人間の指示）。窓の地色は段階で静止（白→薄琥珀→薄赤）にし、
   危険域では**お題の札そのもの**を `animate-fg-alert`（1.8秒周期の opacity 1↔0.35）で点滅させる。
15. **1画面を使い切る縦レイアウト**。試合中画面を `min-h-[calc(100vh-2.75rem)]` の縦 flex にし、
   3列グリッドを `flex-1`。敵の状況・NEXT・主ディスプレイは `h-full` / `flex-1` で縦に伸びる。
16. **敵の盤面を 7×14=98 マスに変更し、自分を除外**。行を `1fr` にして高さいっぱいに引き伸ばす。
   自分の状態はヘッダ（残り/撃破）とランキングで見るため、盤面は「相手だけ」を一望する場にした。

17. **練習モード専用の試合中デベロッパーツールを追加**（人間の指示）。試合画面ヘッダー右に置き、
   ダケン付与（通常/トラップ）・手動クリア報告・攻撃力の直接設定を行う。
   - 実体は `simulateReceive` による S2C 注入（`DakenIssued` / `ComboUpdated`）で、**戦闘ロジックではない**。
   - `backend === "mock"` のときだけ描画する。オンライン対戦では出さない（サーバー権威を侵さない）。
   - 従来 App 下部にあった「手動クリア報告」ボタンはここへ移設し、元の位置からは削除した。
   - 入力欄はキーイベントを `stopPropagation` し、反映後に `blur` する（打鍵判定へキーが漏れない／
     フォーカスが残って打鍵が止まらないようにする）。

18. **お題の制限時間の警告表示を追加**（人間の指示）。主ディスプレイ上端に残り時間バーを出し、
   50%以下で琥珀、25%以下で赤＋バーが点滅、盤面の縁も赤に変わる。
   - 基準時刻は**お題が画面に出た時刻**（表示専用）。サーバーの単調時刻 `issuedAtServerTimeMs` とは突き合わせない。
   - **時間切れの確定はサーバー権威**。バーが 0 になってもクライアントはお題を消さない（`DakenExpired` を待つ）。
   - 制限時間が 60 秒超のものは「実質無制限」とみなして非表示（練習スタブの 999,999ms 対策）。
19. **dev ツールに警告／トラップ失敗の再現を追加**:
   - `警告お題(5秒)`: 出題キューを空にして制限時間5秒のお題を1件出す（`DakenIssued` は末尾に積まれるため、
     先頭に出すには一度空にする必要がある）。
   - `時間切れ`: 現在のお題に `DakenExpired` を流す。
   - `トラップ失敗`: 失敗の見え方を再現（お題を落とす → 被弾スタック +2 → 被弾ダケン2件を発行）。
     **サーバー実装の正典ではなく表示確認用のスタブ**である旨をコード内に明記した。
   - `誘発待ち`: `trapPending` の表示を切り替える。あわせて NEXT パネルのヘッダに
     「💣 誘発待ち」バッジを追加した（被弾スタックパネル廃止で表示先が無くなっていたため）。

20. **画面全体のフラッシュは「ストックの溜まり具合」で出す**（人間の指示）。`fixed inset-0` のオーバーレイを
   `animate-screen-alert`（0.7秒周期）で明滅させる。中央は薄く（背景 7% の赤）、縁だけ強く光らせる
   `box-shadow: inset` にして、**打鍵中のお題の可読性を落とさない**ようにした。
   - トリガーは被弾スタックが危険域（85%以上）に入ったとき。しきい値は `stackLevel()` に切り出し、
     NEXT の地色と画面フラッシュで**同じ基準**を使う。
   - オーバーレイは `pointer-events-none`。クリックを一切奪わない。観戦中は出さない。
   - 画面全体が点滅するため、**NEXT の札ごとの点滅（`fg-alert`）は撤去**した（二重の点滅を避ける）。
     NEXT の地色（白→薄琥珀→薄赤）は段階表示として残す。
   - お題の残り時間は主ディスプレイの帯＋盤面の赤枠のみで警告する（画面フラッシュはしない）。
     計時は `useDakenTimer` に切り出し済み。

## 却下した案

- 画像内の「攻撃効果ログ」等、サーバーが配信していない値を新設すること
  → 表示のためにクライアントで戦闘値を作ることになるため却下。既存の `GameEvent` の範囲で表現した。
- ダークテーマとの二重管理（`dark:` バリアント）→ 今回はモックの1テーマに絞る。
