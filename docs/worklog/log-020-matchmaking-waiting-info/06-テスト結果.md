## 検証中に見つけて直したもの

1. **「まもなく開始」中に参加者一覧が空になる**
   `MatchStart` 受信で reducer が `matchmaking: null` にするため、一覧が「0 人 / まだ誰もいません」になっていた。
   → 3 秒ゲート中は一覧セクションごと非表示にした（決定 #3）。
2. **残り 0 秒のまま数秒固まる**
   カウントダウンが 0 に達しても `MatchStart` が届くまで `0秒` を表示し続けていた。
   → 0 到達時は「まもなく開始します…」に切り替えた（決定 #4）。

## 未検証

- カウントダウン中に minPlayers を割り込んで**中止**されるケース（`counting` が false に戻る経路）。
  実サーバーで再現させるには待機中に離脱するタイミング合わせが必要なため未実施。ロジック上は
  `countdownMs` が消えた status を受けた時点で待機表示に戻る。
