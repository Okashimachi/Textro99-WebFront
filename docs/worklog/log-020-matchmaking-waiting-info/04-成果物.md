## 実装/変更の要点

### 残り秒数（MatchmakingScreen）

```ts
const counting = status?.countdownMs != null && statusReceivedAtMs != null;
const countdownRemainMs = counting
  ? Math.max(0, statusReceivedAtMs! + status!.countdownMs! - now)  // now は useNow(100)
  : null;
```

- 締切 = **受信時刻 + 残り時間**。以降は `useNow(100)` で描画だけを進める。
- `countdownMs` が消えた status（minPlayers 割れでカウントダウン中止）を受けると `counting=false` に戻り、
  「あと N 人でカウントダウン開始」表示へ自動的に戻る。
- 残り 0 では数字を出さず「まもなく開始します…」。

### 参加者一覧（MatchmakingScreen）

- `status.players` をそのまま並べる。自分（`selfDisplayName` 一致）の行を赤地＋「あなた」バッジで強調。
- Bot はマッチング成立時にサーバーが補完するため、この一覧には**人間の参加者だけ**が並ぶ。
- `MatchStart` 後の 3 秒ゲート中は非表示（待機プールは解散済みのため）。

### 参加/離脱の名前（reducer）

- `nameDiff(a, b)` で「a にあって b に無い表示名」を取る。同名複数人に備え件数ベースで突き合わせる。
- 表示文言を作るだけで、判定・集計はしない（docs/rules/01 §1,§3）。
