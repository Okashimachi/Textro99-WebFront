# 05 テスト仕様

## 前提条件

- proto: `v0.1.1+`（`textro-main 42fb05e`）
- サーバー: デプロイ済みの実サーバー（`VITE_WS_URL`）。`minPlayers=2` / `StartCountdownMs=5000`（実測）
- フロント: `npm run dev`（Vite / localhost:5173）
- 起動フロー: タイトル →「テスト用」→「オンライン対戦」→ 名前入力 → 対戦開始

## テストケース

| # | 種別 | 確認内容 | 手順 | 期待結果 |
|---|---|---|---|---|
| 1 | 手動（実サーバー） | 1人で待機中の表示 | 1タブでオンライン参加 | 「あと 1 人でカウントダウン開始」／参加者一覧に自分だけ（自分の行が強調） |
| 2 | 手動（実サーバー） | 2人目参加でカウントダウン開始・**残り秒数が毎秒減る** | 2タブ目で参加し、1タブ目を1秒間隔でサンプリング | 「試合開始まで N 秒」が 5→4→3→2… と減る |
| 3 | 手動（実サーバー） | 参加者一覧が実データで出る | 同上 | 一覧に両者の表示名が並ぶ |
| 4 | 手動（実サーバー） | 参加/離脱が名前付きでログに出る | 同上 | 「{名前} が参加（待機 N / 最少 M 人）」 |
| 5 | 手動（Devモック） | 多人数＋長いカウントダウンの表示 | 待機中に「3. MatchmakingStatus (カウントダウン)」を注入 | 残り 15 秒から減る／参加者 4 人が並ぶ |
| 6 | 手動 | 「まもなく開始」中に一覧が空表示にならない | MatchStart を受けて 3 秒ゲートに入る | 参加者セクションが出ない（「0人 / まだ誰もいません」が出ない） |
| 7 | 自動 | 型検査 | `npx tsc --noEmit` | エラーなし |
