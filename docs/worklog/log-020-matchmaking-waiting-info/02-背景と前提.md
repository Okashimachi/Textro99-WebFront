# 02 背景と前提

## 背景

- log-019 で「待機画面の残り秒数表示をやめイベントログに置換」した（commit `e978ece`）。
  理由は **サーバーが `countdownMs` に残り時間ではなく全体秒数を載せ直していた** ため、
  参加者が増えるたび表示が巻き戻っていたこと。
- 今回、上流（Proto / Server）でこの点が修正され、待機者名の配信も追加された。
  → フロント側で残り秒数表示を復活させ、参加者一覧を追加できるようになった。
