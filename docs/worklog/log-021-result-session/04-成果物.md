## 実装/変更の要点

1. **リザルトはモーダル**。フェーズは `spectating` のまま。背後の観戦画面（ランキング・99人グリッド・戦況ログ）はブロードキャストで更新され続ける。閉じている間は右下に「リザルトを見る」＋残り秒数だけが出る。
2. **自動で次試合へ行かない**を3重で担保。
   - 参加意思（`joinArmed`）が立っているときしか `MatchmakingJoin` を送らない。GameOver で降ろす。
   - GameOver で `setAutoReconnect(false)`。サーバーが切ったらそのまま切れたままにする。
   - 封印中は `MatchStart` を受けても画面を試合中へ戻さない（サーバーが同一接続で次試合を始める実装への保険）。
3. **セッションの終端は1本の出口**。「サーバー切断 → 15秒 → `exitToTitle`」も「タイトルへ」ボタンも同じ `exitToTitle` を通り、必ず `connection.disconnect()` してから `stage="title"` に戻る。
4. **再マッチング**は参加意思と autoReconnect を立て直してから `connection.reconnect()`（1接続=1試合の契約どおり接続を張り直す）。
