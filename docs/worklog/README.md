# docs/worklog — AI作業ログ

AI（Claude Code / Codex / Cursor 等）に出した指示・AIの判断と決定・テスト仕様と結果・トークン消費を、**1タスク＝1ファイル**で記録する場所。

## 目的

- 「なぜこの実装になったか」「どの指示から生まれたか」を後から追える状態にする（AI生成コードの意思決定ログ）。
- テスト仕様と結果を残し、回帰時の確認点を明確にする。
- **トークン消費量とその原因/過程を記録し**、コスト効率の悪い進め方を可視化・改善する。

## 命名規則

```
docs/worklog/log-NNN-{短いkebab-caseの主題}.md
```

- `NNN` は3桁連番（`001` から。**欠番を作らない**）。
- 例: `log-001-webfront-scaffold.md` / `log-002-daken-display-component.md`
- テンプレートは [_template.md](./_template.md)。新規タスク着手時にこれをコピーして番号を採る。

## 記入タイミング

| タイミング | 埋める節 |
|---|---|
| タスク着手時 | 1. 指示 / 2. 背景・前提 |
| 作業中〜完了時 | 3. AIの判断と決定 / 4. 成果物 |
| テスト時 | 5. テスト仕様 / 6. テスト結果 |
| 完了時（必須） | 7. トークン消費 / 8. 振り返り |
