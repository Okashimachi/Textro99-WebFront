## 総括

- **静的検証（型・ビルド）のみ合格**。契約から削除された型への参照が残っていないことは型検査で担保できている。
- **L3〜L9 のブラウザ手動確認が未実施**。特に L5〜L7（予告の自然消滅・蓄積防止・`insertIndex`）は本 PR で新規に入れたロジックで、型検査では正しさが担保できない。マージ前に mock モードで確認すること。
- **S1〜S4 は実施不能**。Render のサービスが suspended 状態（コールドスタートではなく停止）で、実通信の結合検証ができない。サーバー復旧が本 PR の受け入れ条件に含まれるかは人間の判断待ち。
- 申し送り: サーバー側 #77 / #80 が未デプロイのまま本 PR をマージすると、`rank` が常に 0（＝順位がフラット）になり、攻撃が一切発生しない状態になる。**サーバー側のリリース順序と揃える必要がある**。
