# 02 背景と前提

> このタスクが必要になった理由、参照した上流ドキュメント、前提となる制約。

## 背景

- Proto が **v0.1.0 → v0.1.1** に更新され、契約に破壊的変更が入った。vendored な `src/proto/types.ts` を差し替え、依存する実装（入力・reducer・ランキング・HUD）を追従させる必要がある。
- 契約変更は大きく3点:
  1. **攻撃の手動発火が廃止**（server #77）。`AttackRequest` / `AttackFailed` / `OffsetResolved` が削除され、攻撃はサーバーがダケンのノーミスクリアを起点に自動発火する。相殺・撃ち返しの概念そのものが無くなった。
  2. **サーバーが試合中順位を配信**（server #80）。`PlayerSummary.rank` が追加（1=首位、0=未確定）。
  3. `MatchmakingJoin` に `displayName?` が追加。送らないと盤面の名前が接続IDになる。
- 1 に伴い `DakenIssued` に `insertIndex` が入り、被弾ダケンを列の途中へ割り込ませられるようになった。

## 前提・制約

- **`src/proto/types.ts` は vendored（改変禁止）**。Proto 側の写しをそのまま置き、このリポジトリで契約を変更・確定しない（rules/01 §6）。
- **戦闘数値・順位をクライアントで算出しない**（rules/01 §1, §3）。サーバーが配信した値を写して表示するだけ。
- 実サーバー（Render）が現在 **suspended で 503** を返すため、実通信での結合検証ができない。検証は `mock` モード（フロント完結）に限られる。
