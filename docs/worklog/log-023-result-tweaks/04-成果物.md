## 実装の要点

### 1. 文面の切り出し

```
src/share/
  postFormat.ts  ← 文面（ここだけ編集すれば文言が変わる）
  shareText.ts   ← GameOver → ShareText の配線
  xIntent.ts     ← X への遷移
```

`postFormat.ts` は `HASHTAG` / `GAME_LABEL` / `PostValues` / `formatPostText()` を持つ。使う値は `rank` / `koCount` / `maxCombo` の3つで、`toPostValues()` が GameOver から取り出す。

### 3. バッジ非表示

proto のフィールド（`badgeCount` / `badgesTransferred` / `finalBadgeCount`）は受信・保持したまま、**表示側のみ**を落とした。`state` の形は変えていないため、方針が戻れば表示を足すだけで復活できる。

### 4. 入力の振り分け

```
キー入力
 ├ 数字 かつ お題に数字が含まれる  → 打鍵（TypingJudge）
 ├ 数字 かつ 上記以外               → StrategySelect（従来どおり）
 ├ a-z / A-Z / -                    → 打鍵
 └ それ以外                          → 無視
```

お題に数字があるかの判定は `App` 側（`/[0-9]/.test(state.activeDaken[0]?.text ?? "")`）。入力層はお題を知らない。

### 5. テストモードの隠し方

`?test=1` を付けたときだけタイトルに「テスト用」が出る。付けない場合は入口が常に `play` になり、モード選択・練習モード・開発ツール・Devモック注入・マッチングのイベントログがすべて出なくなる。
