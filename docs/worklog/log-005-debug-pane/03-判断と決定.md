- RawStateDebugPane は「整形表示のみ」。state タブ / last envelope タブを切替。トグルで最小化（docs/rules/02 §2）。
- サーバー無しで reducer/表示を検証できるよう、`WsConnection.simulateReceive(envelope)` を追加（実受信経路 `handleRawMessage` と同一分岐を通す）。リプレイ/テストにも使える汎用アフォーダンス。Unity 側もミラー可能。
- `src/dev/mockMessages.ts` に S2C の例列を用意し、App にモックボタンを配置。これで #5 reducer の畳み込み（特に PlayerListDelta 差分マージ）を実ブラウザで確認した。
- App にて 接続生成 → `useGameState` → RawStateDebugPane を配線（本 Issue が最初の「動く配線」）。実サーバ自動接続は無効（`autoReconnect:false`・統合フェーズで有効化）。
