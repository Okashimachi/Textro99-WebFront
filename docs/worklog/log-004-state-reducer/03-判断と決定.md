# 03 判断と決定

- `useReducer` のみ（状態管理ライブラリ不使用・docs/rules/02 §3）。
- **戦闘数値をローカル算出しない**（docs/rules/01 §1,§3）。`ComboUpdated`/`DakenStackUpdated`/`DifficultyUpdated` はサーバー値をそのまま格納。KO 時も alive を自前で立てず、`PlayerListUpdated`/`PlayerListDelta` を正典として反映（KO はイベントログ記録のみ）。
- `PlayerListDelta` は `playerId` で突合し、`undefined` フィールドは変化なしとしてマージ。未知プレイヤーの差分はフルスナップ待ちで無視。元の並び順を保持。`aliveCount` は Delta 付随値で更新。
- `AttackIncoming` は配列に積み、`OffsetResolved`/`GameOver` で除去。撃ち返しの新規予告は別 `AttackIncoming` で届くため、ここでは相殺予告の除去のみ。
- `activeDaken` は `MatchStart.initialDaken` 起点、`DakenIssued`（配列一括）で追加、`DakenExpired` で除去。
- EventLog の React key 安定化のため純粋な `eventSeq` カウンタを ViewModel に持たせた（`Date.now()` や配列長に依存しない）。
- 直近 Envelope は `useGameState` フックで保持し #6 デバッグペインへ渡す。
