# 03 判断と決定

- 6 コンポーネントを機能単位に分割（docs/rules/02 §1）。各々 proto DTO / ViewModel のみ入力、内部にゲーム判定ロジックを持たない（docs/rules/02 §7）。
- `DakenDisplay`: 出題ダケンと打鍵ハイライト。ハイライトは表示専用 `typedPrefix`（#8 が公開予定）を色分けするだけ。判定はしない。
- `ComboGauge`/`DakenStackView`: 値はサーバー由来をそのまま表示。スタックの危険域色は「表示のしきい値色替え」であって戦闘判定ではない。
- `AttackWarningBar`: 残り猶予は表示用クライアントカウントダウン（`useNow`）。着弾・相殺判定はサーバー権威で行わない。
- `StrategySelector`: 選択中ハイライトのみ。送信は #7。既定値(4)をローカルで勝手に送らない。
- `EventLog`: reducer が写したイベントを並べるだけ。
- 合成コンテナ `InMatchScreen` を用意し、`ScreenRouter` の inMatch/spectating で使用（観戦時はトーンダウン表示）。
- `selectedStrategyId` は #7 の入力層から props で受け渡し。
