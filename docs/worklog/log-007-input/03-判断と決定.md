# 03 判断と決定

- 操作は3種のみ（docs/rules/01 §7）: Enter→`AttackRequest`、0-9→`StrategySelect`、文字キー→打鍵判定へ。それ以外は無視。修飾キー付き・IME 変換中も無視。
- **1文字ごとに送信しない**（docs/rules/01 §2）。文字キーは `onCharKey(char)` で #8 TypingJudge へ渡すだけ。判定結果を `DakenClearReport`（ダケン単位）に集約して送るのは #8 の責務。
- #8（TypingJudge 本体）は **proto の共有ローマ字テーブル未実装のため上流ブロック中**。本層はテーブルに依存しない差込点 `onCharKey` を用意して先行実装。判定ロジックは含めない。
- `AttackRequest.consumedCombo` はローカル算出せず、表示中コンボ値 `state.combo.value` をそのまま添付（proto 注記: サーバーは現状無視・全消費）。
- 有効化は `inputActive`（lifecycle #9）に連動し `inMatch` のみ。観戦・非対戦画面ではリスナを張らない。
- 検証性向上のため `WsConnection.onOutbound` を追加（未接続でも送信試行を観測）。dev の送信ログ表示に利用。
