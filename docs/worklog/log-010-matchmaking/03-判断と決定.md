# 03 判断と決定

- `MatchmakingScreen` は `MatchmakingStatus` DTO のみを表示。Join/Leave の送信は props コールバック（App が `connection.send(MatchmakingJoin/Leave)` で配線）。
- カウントダウンは表示専用。reducer に `matchmakingReceivedAtMs`（受信時刻）を追加し、`countdownMs - (now - received)` を `useNow` で描画。残時間はサーバー値からの表示計算であり判定ではない。
- **ライフサイクル修正**: 待機フェーズをローカル意図 `seeking` 駆動に変更（従来は `state.matchmaking` 有無でも待機になり、Leave してもサーバーの status が state に残ってタイトルへ戻れなかった）。`leaveMatchmaking` アクション（intent→idle）を追加し、離脱でタイトルへ戻る挙動をブラウザ検証で確認。
- タイトルの「参加」・リザルトの「再マッチング」も Join 送信を伴うよう配線。
